# Версия с выбором курса нажатием на карточку

Это отдельная копия версии с улучшением удобства. Обычные цветные карточки теперь выбираются нажатием на карточку; повторное нажатие снимает выбор. Флажок внутри карточки показывает состояние и позволяет выбирать курс с клавиатуры. Кнопка просмотра программы и раскрытие описания работают отдельно и не переключают выбор.

Запуск из корня проекта на Windows:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/Start-Card-Selection.ps1 -NoBrowser
```

Откройте http://127.0.0.1:8774/. Сервер должен оставаться запущенным. Если порт занят, выберите свободный с помощью `-Port`. Документы по-прежнему работают в режиме предварительного просмотра.

Самостоятельные исходники находятся в `work/consulting-card-selection-version/`, собранный сайт — в `outputs/consulting-card-selection-version/`. Пересборка:

```powershell
python -X utf8 work/consulting-card-selection-version/build_card_selection.py
```

Проверяйте выбор и снятие нескольких курсов в карточках и калькуляторе, работу кнопок программ, возврат из формы и поведение на телефоне. Предыдущие версии не меняются.
