# TopEngineer — Tekla Structures training website

Самостоятельный проект текущей **цветной версии** сайта TopEngineer: четыре курса, программы в двух частях, калькулятор, сравнение длительностей, сертификаты и B2B-документы.

**Для Codex на новом компьютере:** начните с [CODEX_HANDOFF.md](CODEX_HANDOFF.md). Там есть готовое первое сообщение, порядок запуска, карта файлов и оставшиеся задачи. Репозиторий: [wildomen-crypto/topengineer-training-website](https://github.com/wildomen-crypto/topengineer-training-website).

**Отдельный вариант с боковыми полями (27 октября):** запустить `Start-Contained.cmd` и открыть **http://127.0.0.1:8775/**. Максимальная ширина страницы — 1600 px. Исходники: [work/consulting-contained-version](work/consulting-contained-version/README.md), готовый сайт: `outputs/consulting-contained-version`. Прежняя версия с выбором карточек и книгами продолжает запускаться через `tools/Start-Card-Selection.ps1` на порте 8774; варианты можно развивать независимо.

**Отдельный вариант с интерактивным объяснением урока (27 октября):** запустить `Start-Interactive-Lesson.cmd` и открыть **http://127.0.0.1:8776/#how-training-works**. Вместо фотографии в блоке обучения — три переключаемых варианта: два рабочих места с гибкими соединениями, этапы урока и вид мониторов ученика / преподавателя. Исходники и инструкция: [work/consulting-interactive-lesson](work/consulting-interactive-lesson/README.md). Прежние версии на портах 8774 и 8775 сохранены.

**Основная версия с выбором карточек:** **http://127.0.0.1:8774/**. Белая страница со статичным штатным светло-голубым фоном у разделов **How the training works**, **Choose your training format** и **Your certificate of completion**. Фон не меняется при прокрутке. Запуск: `tools/Start-Card-Selection.ps1`.

Рамка калькулятора заканчивается после строки книг. Под ней — итог без заливки и обводки: на широком экране примечания находятся слева от суммы, на узком — под суммой. Кнопки документов расположены ниже. В этой версии по умолчанию выбраны Level 1 на 2 дня для 1 человека и один комплект книг: EUR 539. Книги можно отключить.

**Отдельная страница с чередованием фона:** после того же запуска открыть **http://127.0.0.1:8774/alternating-backgrounds.html**. Вводный блок и описания курсов остаются белыми; далее чередуются белый и штатный светло-голубой фон темы. Эксперимент сохранён отдельно от текущей версии с тремя статичными акцентами. Страницы собираются через `work/consulting-card-selection-version/build_card_selection.py` и используют общие стили и калькулятор.

**Отдельная страница с фоном при прокрутке:** **http://127.0.0.1:8774/scroll-background.html**. Общий фон плавно меняется по мере перехода между разделами. Во время чтения вводного блока и описаний курсов фон белый. Палитра и точка переключения находятся в `work/consulting-card-selection-version/scroll-background.js`, длительность перехода и настройка уменьшенного движения — в `scroll-background.css`. Страница использует исходную белую версию; её содержимое, калькулятор и остальные варианты сохранены. Сборка — тем же `build_card_selection.py`.

## Как открыть дома на Windows

1. Скачать репозиторий через **Code → Download ZIP** или клонировать его, затем распаковать.
2. Дважды щёлкнуть **Start-Card-Selection.cmd** в корне проекта.
3. Откроется **http://127.0.0.1:8774/**. Оставить окно сервера открытым во время работы.

Установленный PHP 8.1+ используется автоматически. Если его нет, скрипт скачивает официальный PHP 8.4.27 в локальную папку проекта и проверяет SHA-256. Python для просмотра сайта не нужен. При сообщении Windows об отсутствующем VCRUNTIME понадобится официальный Microsoft Visual C++ Redistributable x64: https://aka.ms/vs/17/release/vc_redist.x64.exe.

Сайт нельзя полноценно проверить двойным щелчком по index.html: нужны локальный сервер и PHP для документов. GitHub Pages не выполняет PHP; репозиторий предназначен для хранения исходников и продолжения разработки.

## Как продолжить работу в Codex

Открыть корневую папку этого проекта. Сначала прочитать **PROJECT_CONTEXT.md**. Текущая страница — `outputs/consulting-card-selection-version/index.html`. Редактируемые исходники — `work/consulting-card-selection-version/`.

Проект общедоступен: скачать ZIP или клонировать его можно без входа в GitHub. Для дальнейшей работы удобнее клонирование: оно сохраняет историю Git. Для отправки изменений в этот репозиторий нужен аккаунт с правом записи; владелец — **wildomen-crypto**. ZIP подходит для запуска и локальных правок.

Для пересборки понадобится **Python 3.12+**:

```powershell
python -m pip install -r requirements-dev.txt
python -X utf8 work/consulting-card-selection-version/build_card_selection.py
```

После сборки обновить страницу браузера. Базовая разметка остальной страницы находится в `base-page.html`, программы — в `course-programme.json`. CSS/JS редактируются в work и копируются сборкой. Сборка полностью самостоятельна, прошлые проекты не нужны.

## Что ещё нужно перед приёмом оплаты

Сейчас работает **PREVIEW**, без банковских инструкций. Карточка компании с реквизитами EUR получена и сохранена отдельно от Git. Ожидаются ответы по налогам и оставшимся условиям оплаты. Черновик договора требуется доработать. Подробности: `docs/Вопросы-для-бухгалтерии.md` и `docs/Инструкция-по-переносу.md`.

Реальные банковские настройки, базы заказов, клиентские документы, токены и локальные журналы в репозиторий не включены. Данные локального просмотра создаются вне проекта в пользовательской папке Windows. Они не переносятся через GitHub.

Это снимок для продолжения разработки. Функциональность исходного Bitrix-сервера, отправка email, банковская сверка, SEF и окончательные налоговые документы не эмулируются.
