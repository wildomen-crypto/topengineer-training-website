# Передача сайта в Codex на другом компьютере

Обновлено 27 октября 2026 года. Репозиторий: https://github.com/wildomen-crypto/topengineer-training-website (Public). Скачать или клонировать проект можно без входа в GitHub. Это полная самостоятельная копия выбранной цветной версии. Прежний компьютер, предыдущие макеты и история старого чата для запуска не нужны.

## Что сделать владельцу

1. Открыть репозиторий. Для скачивания вход в GitHub не требуется. Для отправки изменений нужен аккаунт с правом записи; владелец — **wildomen-crypto**.
2. Лучше клонировать его через GitHub Desktop или Git, чтобы затем сохранять изменения обратно. Для простого запуска можно выбрать **Code → Download ZIP** и распаковать архив.
3. Открыть **корневую папку проекта** в Codex. В ней находятся `AGENTS.md`, `README.md`, `Start-Card-Selection.cmd`, папки `work` и `outputs`.
4. Вставить сообщение из следующего блока. Пароли или токены в чат не нужны: авторизация выполняется обычным способом через GitHub.

## Первое сообщение для нового чата Codex

> Продолжаем разработку сайта TopEngineer из этого репозитория. Сначала прочитай AGENTS.md, CODEX_HANDOFF.md, PROJECT_CONTEXT.md и README.md. Проверь полноту файлов и запусти текущую версию с выбором карточек (work/consulting-card-selection-version, порт 8774) локально с работающим PHP и созданием предварительных документов. Если порт 8774 занят, выбери свободный локальный порт и сообщи ссылку. Дизайн, тексты, программы курсов и расчёты при запуске не меняй. Не подключай реальные платежи и не загружай приватные данные в Git. После проверки кратко сообщи, что работает и какие задачи остаются. Следующее изменение я задам отдельно.

## Первый запуск для Codex

Работать относительно корня **этого** репозитория. Не искать прежнюю папку `C:/Users/student/...` и не копировать ничего из другого проекта.

Просмотр на Windows, без Python и без пересборки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/Start-Card-Selection.ps1 -NoBrowser
```

Открыть `http://127.0.0.1:8774/`. Сервер должен оставаться запущенным. Для владельца эквивалентный запуск — двойной щелчок по `Start-Card-Selection.cmd` (с автоматическим открытием браузера).

Если порт занят:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/Start-Card-Selection.ps1 -Port 8777 -NoBrowser
```

Не останавливать неизвестный процесс только ради порта. Скрипт задаёт разрешённые адреса формы для выбранного порта. При закрытии окна/остановке запуска завершается и локальный сервер.

`-SmokeTest` запускает сервер, проверяет preview API и сразу останавливает его. Для постоянного просмотра этот параметр не использовать.

Скрипт использует подходящий установленный PHP или скачивает официальный переносимый PHP с проверкой SHA-256. Для первой загрузки runtime нужен интернет. Требуются PHP 8.1+ и расширения DOM/XML, mbstring, PDO_SQLite, GD, ZipArchive. Если в установленном PHP нет расширений, использовать переносимый `.runtime/php84/php.exe` или установить расширения; не заменять сервер на Python. При ошибке VCRUNTIME нужен Microsoft Visual C++ Redistributable x64 из ссылки в README.

На macOS/Linux: установить PHP с перечисленными расширениями, затем запустить из корня:

```sh
php -S 127.0.0.1:8771 -t outputs/consulting-card-selection-version work/consulting-card-selection-version/preview_order_router.php
```

В этом ручном режиме открыть http://127.0.0.1:8771/: он соответствует разрешённым адресам generic preview без банковских данных. Windows launcher сам настраивает порт 8774. Для другого порта при ручном запуске нужно отдельно задать `TRAINING_ORDER_CONFIG` с соответствующим `allowed_origins`, сохранив режим preview. Рабочий хостинг устанавливается по `docs/Инструкция-по-переносу.md`.

## Проверка после запуска

- Главная страница открывается; изображения, шрифты, исходный Bootstrap и цветные карточки загружаются без отсутствующих локальных ресурсов.
- Калькулятор начинается с **Level 1, 2 days, 1 participant + 1 electronic book set, EUR 539**. При добавлении нового курса — 2 дня и 1 участник.
- Для каждого курса доступны 2/5/10 дней, 1–20 человек; для 5/10 дней минимальная оплата за троих. 10 дней стоят вдвое дороже 5 дней.
- Конец курса считается по календарным дням включительно: например 29 декабря + 10 дней → 7 января. Даты не обязательны для подготовки документов.
- В программах **Part 1 и Part 2**, обе части видимы одновременно на широком экране. Всего четыре курса и 352 темы.
- Кнопка **Prepare order documents** ведёт на отдельную страницу `/training-order/`. Рядом **Download proposal PDF** скачивает краткое КП без обязательного ввода реквизитов. В форме тоже доступно скачивание КП; введённые данные компании автоматически используются в обоих документах. Возврат **Edit selected items** восстанавливает курсы, даты и заполненные реквизиты.
- Для проверки документов использовать только вымышленные компанию/контакт и адрес `training@example.com`. Получить КП, pro forma и при необходимости черновик договора; проверить скачивание PDF и ZIP.
- Режим **PREVIEW**, реальные банковские инструкции отсутствуют. Генерация документов не означает оплату; автоматическая отправка email не подключена.
- При правках интерфейса проверять минимум телефон 390 px, планшет 768 px, ноутбук 1366 px, широкие экраны 1920 и 2560 px. Особое внимание — изображению и соседнему тексту, четырём колонкам тем и полной таблице цен в диалоге.

Это критерии повторной проверки на новом ПК, а не заявление, что каждый размер заново проверен при переносе.


Сборка проверяет идентификаторы HTML, порядок и сохранность всех 352 тем, видимость обеих частей и отсутствие изменений посторонних блоков. Она создаёт `training-order/data/catalogue.json` из тех же программ и цен. Отдельно править только этот сгенерированный JSON нельзя.

В исходном JSON/именах селекторов ещё встречаются `days` и `day`. Это внутренняя совместимость структуры, на странице выводится **Part**. Не переименовывать поля без необходимости.

Все необходимые изображения, шрифты, исходные стили и Dompdf с лицензиями уже включены. Для обычного запуска и PDF Composer, npm, внешняя база, Bitrix и обращения к старому сайту не нужны. `prepare_order_runtime.py` — вспомогательное восстановление зависимостей; при наличии `vendor` запускать его не требуется.

## Что уже согласовано

Полные правила и терминология — в `PROJECT_CONTEXT.md`. Ключевые ограничения:

- Сохранять оригинальный Bootstrap, широкую вёрстку и утверждённые цвета четырёх курсов. Карточки длительности все синие, 10 дней отмечены лентой **Popular**.
- Базовый курс нужен перед остальными; Levels 2–4 затем доступны в любом порядке. Пятый курс не добавлять.
- 10 дней — 5 дней обучения + 5 дней работы над **проектом самого заказчика**, с существенно большей практикой.
- Условия pro forma: срок 6 календарных месяцев с ограничением последним днём целевого месяца; перенос дат без изменения стоимости; возврат за вычетом банковских комиссий без другого штрафа.
- КП включает выбранные курсы, их цены и программы, а также отдельно предложения остальных курсов с ценами и программами. Дополнительные курсы не включаются в сумму счёта.
- Новые цены/условия не переписывают ранее сохранённые заказы. Расчёт на сервере обязателен, цена от браузера не считается доверенной.

## Что остаётся сделать — не путать с готовыми функциями

1. Сохранение реквизитов и отдельная группа контактных полей реализованы 26 октября. В текущей вкладке используется sessionStorage; персональные данные не помещаются в URL/localStorage. Компактная раскрывающаяся сводка заказа на телефоне ещё остаётся предложением, автоматически добавлять её при запуске не нужно.
2. Вопросы бухгалтерии и оставшиеся платёжные условия — `docs/Вопросы-для-бухгалтерии.md`. Владелец пока не готов дать ответы. Не спрашивать их повторно только ради запуска preview.
3. Окончательный договор, налоговые правила, процент/график предоплаты и комиссии входящего платежа ещё не утверждены. Обязательная 100% предоплата не согласована. Сохранять `payment_terms_approved = false` и не включать live.
4. Автоматическая рассылка, сверка банковских поступлений, SEF, окончательный налоговый счёт, электронная подпись и карточная оплата не подключены. Банковский перевод — выбранный способ будущей оплаты.
5. Сайт сохранён в GitHub для разработки; это не публикация рабочего PHP-сайта на хостинге. GitHub Pages не исполняет PHP. Перенос на рабочий Bitrix выполнять отдельно, не перезаписывая его целиком.

## Приватные данные и сохранение работы

Реальная карточка компании и банковский конфиг сознательно не включены. На новом ПК формы, расчёт и предварительные документы работают без них. Если понадобятся реальные платежи, владелец отдельно передаст приватный конфиг защищённым способом; не просить размещать его в GitHub.

Windows launcher создаёт настройки и runtime в игнорируемой `.runtime/`. Локальная база и документы находятся в `%LOCALAPPDATA%/TopEngineer/training-order-preview-card-selection`, вне публичного сайта. Они не переносятся через GitHub. Тестовую БД не использовать для рабочих заказов.

Перед отправкой изменений проверить `git status`, не добавлять `.runtime`, `qa`, `.revisions`, `.env`, приватные настройки, базы, клиентские PDF, журналы и токены. Сохранять в одном изменении исходники и пересобранный `outputs`; пользователь должен иметь возможность открыть проект без сборки. При работе с Git использовать текущий аккаунт владельца; не переподключать репозиторий к иному аккаунту без его указания.

Владелец общается по-русски, сайт и документы — на английском. Объяснять коротко и понятным языком. Английскую терминологию Tekla переводить по смыслу, при неоднозначности задавать точечный вопрос. Уточнения Polybeam/Twin profile, Seam, reference model и Template Editor сохранены в `PROJECT_CONTEXT.md`.

## Проверка КП и инвойса после изменений

Для текущей версии на порте 8774 использовать `python tests/test_book_orders.py`: набор проверяет курсы вместе с книгами и отдельно, цены, наследование данных и размещение документов на странице. Нужны Python-пакеты `requests` и `PyMuPDF`. Используются вымышленные компании; PDF сохраняются в игнорируемой `.runtime/qa-books/`. С рабочей оплатой тест не запускается.

Сохранённый `tests/test_proposals.py` относится к прежней версии на порте 8771. Для него отдельно запустить `tools/Start-Windows.ps1`; он проверяет 60 ставок, наборы курсов, длинные реквизиты, общие данные клиента, CSRF, ZIP, срок счёта и 352 темы.
