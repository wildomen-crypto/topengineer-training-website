# Работа над TopEngineer Training

- При первом открытии на другом компьютере прочитать CODEX_HANDOFF.md, PROJECT_CONTEXT.md и README.md. Выполнить описанный там запуск без изменения дизайна.
- Это самостоятельная текущая цветная версия, не импортировать старые варианты из внешних папок.
- Основные изменения вносить в work/consulting-course-colours, затем запускать build_parallel.py. Сохранять готовый outputs для просмотра без сборки.
- Сохранять исходные Bootstrap-стили, адаптивность, английскую терминологию Tekla и текущие правила расчётов.
- Не добавлять реальные реквизиты, клиентские заказы, PDF клиентов, .env, токены и локальные runtime-файлы в Git.
- Режим оплаты остаётся PREVIEW, пока владелец не предоставит подтверждённые банковские и налоговые данные. Не подменять pro forma окончательным налоговым счётом или SEF-документом.
- Объяснять изменения простым языком, особенно если меняются расчёты или оформление заказа.
- Не считать предложения из разговора выполненными: незавершённые доработки формы перечислены в CODEX_HANDOFF.md. Выполнять их только по следующему заданию владельца.
- Не использовать абсолютные пути, имена пользователя Windows и установленный runtime с прежнего компьютера. Все команды выполнять из корня этого репозитория; для просмотра использовать Start-Windows.cmd или tools/Start-Windows.ps1.
- После изменений пересобирать outputs, проверять затронутый сценарий и сохранять исходники вместе с результатом. Перед отправкой в Git проверить отсутствие приватных данных и временных файлов.
